## Introduction

any2nix-website is a web application used to translate from various formats to [Nix](https://nixos.org/).

## Building

This crate requires external dependencies from [npm](https://www.npmjs.com/) to be built. Use your preferred JavaScript runtime to install them.

Examples:

- Bun

```bash
bun install
```

- Node

```bash
npm install
```

- Yarn

```bash
yarn install
```

And so on.
