# [any2nix: Serialization-powered Nix Converter](https://docs.rs/any2nix)

[![License](https://img.shields.io/badge/license_-GPLv3+-822422?logo=GNU&logoColor=black&labelColor=white)](LICENSE)

## Introduction

any2nix is a suite of conversion tools from multiple formats to [Nix](https://nixos.org/) based on [data serialization](https://docs.rs/serde).
