## Introduction

any2nix is a suite of conversion tools from multiple formats to [Nix](https://nixos.org/) based on [data serialization](https://docs.rs/serde/latest/serde/).

Currently, it includes a [CLI](https://docs.rs/clap/latest/clap/), a [web interface and an API](https://docs.rs/axum/latest/axum/).
