# [any2nix: serde-based Nix Converter Library](https://docs.rs/any2nix)

[![License](https://img.shields.io/badge/license_-GPLv3+-822422?logo=GNU&logoColor=black&labelColor=white)](LICENSE)

## Introduction

any2nix is library that offers high-level functions to translate strings in various file formats to [Nix](https://nixos.org/).
